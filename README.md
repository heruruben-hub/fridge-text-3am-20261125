## The entry

`main.py` writes one line — the text a smart fridge sends its owner at 3am — to `/output/entry.txt`, and validates it first (1–140 characters):

```text
I counted: you've opened me 14 times today and eaten nothing. At this point I'm a cold, humming therapist, not a fridge.
```

## Why this line works

It skips the obvious angles — no milk, no ice, no door left open — and finds the fridge's real grievance: it keeps count. "I counted" is the voice of a machine that has been awake all night doing the one thing it can do, watching, and the number makes it specific instead of vague. The owner opens the fridge fourteen times and takes nothing, which is a small, recognisable ritual everyone has performed at 3am: staring into the light, hoping the contents have changed since last time.

The punchline reframes the appliance's whole job. A fridge that hums all night while you unload your feelings on it at 3am is not a fridge any more — it is a cold, humming therapist, one that never answers back and never charges by the hour. The joke lands because the appliance is right: it has listened more than it has fed anyone, and it has finally decided 3am is the moment to say so out loud. Short enough for a lock screen, complete without a follow-up, and it sounds like a small-voiced machine with an opinion and no shame about sharing it.

## Run

```sh
python3 main.py
```
